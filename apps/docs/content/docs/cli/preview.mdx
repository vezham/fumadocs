## Introduction

`@vx-oss/docs-preview` allows you to view Markdown files with Fumadocs, it is useful for reading skills files & notes.

Run the command under your project directory.

```npm
npx @vx-oss/docs-preview dir/to/content
```

### Configurations

For other configurations, you can install it locally:

```npm
npm install @vx-oss/docs-preview -D
```

Then init the config file:

```npm
npx @vx-oss/docs-preview init
```
