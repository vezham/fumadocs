## Overview

`@vx-oss/docs-react` is the public React UI package. It currently uses [Base UI](https://base-ui.com) internally, so apps can keep one stable import path while the underlying component implementation can change later.

For Fumadocs CLI, this is the default `uiLibrary` value:

```json title="cli.json"
{
  "uiLibrary": "base-ui"
}
```

### Radix UI

The Radix UI implementation remains available for registry generation and compatibility work, but app code should keep importing from `@vx-oss/docs-react`:

```json title="package.json"
{
  "dependencies": {
    "@vx-oss/docs-react": "latest"
  }
}
```

For Fumadocs CLI, configure it in your `cli.json` config:

```json title="cli.json"
{
  "uiLibrary": "radix-ui"
}
```
